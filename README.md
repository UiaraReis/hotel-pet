# Hotel Pet

Projeto da disciplina de Programação Web II (UESB), desenvolvido por Uiara Reis Costa Santana, com orientação do professor Lucas Santos de Oliveira.

## Sobre o projeto

O Hotel Pet é um sistema de gerenciamento de estadia de pets. Nesta etapa foi desenvolvida a visão do Gerente, usando apenas HTML, CSS e JavaScript, sem bibliotecas ou frameworks. Como não há backend, todos os dados são estáticos.

## O que o site faz

- **Navegação:** o menu lateral troca entre as telas de Reservas, Pets, Usuários e Configurações.
- **Reservas:** busca por id, proprietário, pet e status, com os botões Pesquisar e Limpar. O gerente pode editar as reservas, inclusive as finalizadas.
- *Pets:* busca, edição e exclusão de pets.
- *Usuários:* busca e troca da função do usuário entre cliente, funcionário e gerente.
- *Configurações:* alteração do valor da diária e do número de vagas disponíveis.

## Como abrir

Baixe os arquivos e abra o index.html em qualquer navegador.

## Arquivos

- index.html: estrutura das telas
- style.css: estilo da página
- script.js: navegação, buscas e edição das tabelas
